# Linear_Memo
A tool may assist your memory
Build with Tauri and Vue.js
UI: Quasar Framework

## 介绍

Linear_Memo是一个基于Tauri和Vue.js的跨平台桌面和移动应用，旨在帮助用户提高记忆能力。

## 功能

### 背卡片界面

- 仿照Anki的记忆卡片,同时加入了复习次数和复习时刻的显示
  - 复习次数：已经复习的次数
  - 复习时刻：下一次复习的具体时间
- 记忆卡片的颜色会随着复习次数的增加而逐渐变浅，以提醒用户及时复习
- 完整移植TUI_fully.py的背单词功能和线性反馈算法

### 卡组管理界面

- 卡组管理界面，可以创建、编辑、删除卡组
- 卡组内可以添加、删除、编辑卡片

### 统计分析界面

- 统计分析界面，可以查看每日、每周、每月的复习情况,像github home页面的统计图一样
- 统计分析界面，可以查看卡组的复习情况

### 设置界面

- 设置界面，可以设置背单词的速度、复习间隔、复习天数等参数
- 设置界面，可以设置卡组的默认排序方式、默认卡片颜色等参数

## 数据库

- 采用SQLite作为数据库，存储单词、复习次数、复习时刻等信息
- 替代原有的NMF文本文件存储方式

## 原理

- 根据记忆半衰理论，代入点解出对应负指数函数，推算下一次复习时刻

## 优点 （相比Anki）

- 能够线性反馈记忆情况
- 无硬性复习安排
